------------------------------------------------------------------------
HOW TO INSTALL & USE IN ANY APP (FOR TRANSLATION & TYPING)
------------------------------------------------------------------------

1. WINDOWS:
   - Right-click on "NotoSansMeeteiMayek-Regular.ttf" (and Bold).
   - Select "Install" or "Install for all users".
   - Open MS Word, Notepad, Excel, or Photoshop: select font "Noto Sans Meetei Mayek".

2. MAC (macOS):
   - Double-click on "NotoSansMeeteiMayek-Regular.ttf".
   - In Font Book preview window, click "Install Font".
   - Now available in Pages, Keynote, TextEdit, Word, Figma, and Browser.

3. ANDROID:
   - In translation or note-taking apps that support custom fonts (e.g., WPS Office, Phonto, or system font changers):
     import "NotoSansMeeteiMayek-Regular.ttf".
   - Android 10+ natively renders Unicode Meetei Mayek when this font is selected.

4. LINUX:
   - Copy the .ttf files to ~/.local/share/fonts/ or /usr/share/fonts/
   - Run: fc-cache -f -v

5. WEB / CSS APPS:
   Use in CSS:
   @font-face {
     font-family: "Noto Sans Meetei Mayek";
     src: url("NotoSansMeeteiMayek-Regular.ttf") format("truetype");
   }
